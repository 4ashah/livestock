# E2E TESTING

## Deterministic Seed Users
Testing/E2E seeds create six active role users only:

| Email | Role |
|---|---|
| `dataentry@livestock.dev` | DataEntry |
| `farmmanager@livestock.dev` | FarmManager |
| `accounts@livestock.dev` | Accounts |
| `operationsmanager@livestock.dev` | OperationsManager |
| `admin@livestock.dev` | CompanyAdministrator |
| `sysadmin@livestock.dev` | SystemAdministrator |

`Viewer` is retired and must not be seeded into new E2E databases.
