# USER GUIDE

## Your Role Determines Your Access
The application now uses six active roles:
- Employee
- Farm Manager
- Accounting
- Manager
- Admin
- System Admin

`Viewer` is no longer an active role.

## What Employee Can Do
Employee users can:
- View farms and livestock
- Register livestock
- Record newborns
- Add weight
- Add comments and activities
- View the Active Livestock operational report

Employee users cannot manage finance, users, settings, companies, or audit logs.

## What Farm Manager Can Do
Farm Managers can do all Employee work plus operational actions such as livestock editing, intake, discharge, losses, sales creation, operational documents, and operational reporting in their permitted scope.

## What Accounting Can Do
Accounting users handle customers, suppliers, invoices, payments, receipts, expenses, and financial reports within their company.

## Manager, Admin, and System Admin
- Manager: company-wide operational oversight plus approved financial visibility
- Admin: full company-scoped administration
- System Admin: cross-company system administration

## Important Note
Menus help you navigate, but the server independently enforces your permissions on every request.
